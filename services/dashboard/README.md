# dashboard (React)

Protected UX screens with live updates. Calls the Ledger and Risk REST APIs and
subscribes to the realtime gateway for `market.ticks` / `risk.updates`.

- Consumes REST: `docs/contracts/openapi/ledger.openapi.yaml`, `docs/contracts/openapi/risk.openapi.yaml`
- Status: Phase 0 placeholder (implemented in a later phase).
